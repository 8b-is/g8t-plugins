# SNES (65816 / PPU)

## CPU
- Ricoh 5A22 (65816 variant) @ ~3.58 MHz.
- 16-bit accumulator and index registers, 24-bit addressing.
- Native vs emulation mode; direct page instead of zero page.

## PPU / video limits (hard rule #3)

| Limit | Value |
|---|---|
| Sprites total | 128 |
| Sprites per scanline | 32 |
| Sprite sizes | two sizes at a time (8×8 to 64×64) |
| Colors per palette | 16 (with sub-palettes) |
| Background layers | 4 (BG1–BG4) |
| Mode 7 | 1 background layer, rotation/scaling |

## HDMA

- HDMA for per-scanline effects (color math, scroll, HDMA tables).
- DMA budget is part of the frame cycle budget.

## Banks

- 24-bit addressing; bank switching via memory map registers.
- Name the mode (LoROM vs HiROM) and bank layout before coding.

## Toolchain

- WLA-DX (`wla-65816`) is the multi-platform standard; asar and cc65 also target 65816.

## Common failure

- Writing to VRAM outside vblank/forced blank → corruption.
- Exceeding 32 sprites/line → drop (not flicker; hardware drops sprites silently).
