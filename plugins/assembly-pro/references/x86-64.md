# x86-64 (SysV AMD64)

## Register roles

| Register | Role | Callee-saved? | Notes |
|---|---|---|---|
| rax | return value | No | |
| rdi, rsi, rdx, rcx, r8, r9 | arguments 1–6 | No | |
| rbx, rbp, r12, r13, r14, r15 | callee-saved | Yes | must be preserved |
| rsp | stack pointer | — | 16-byte aligned at `call` |
| r10, r11 | caller-saved scratch | No | r11 = syscall clobber |

## ABI rules

- **Stack:** 16-byte aligned before every `call`. The red zone (128 bytes below `rsp`) is
  usable only in leaf functions that do not call anything.
- **Return:** `rax` (and `rdx` for 128-bit). Floating point in `xmm0`–`xmm1`.
- **Varargs:** `al` = number of vector registers used.
- **Red zone:** valid only if the function is a leaf (no `call`).

## Call template

```asm
; prologue (non-leaf)
push    rbp
mov     rbp, rsp
sub     rsp, N          ; keep rsp 16-byte aligned
push    rbx             ; callee-saved if used
push    r12             ; callee-saved if used
; ... body ...
pop     r12
pop     rbx
leave
ret
```

## AVX-512 note

AVX-512 can trigger downclocking on some cores. A faster inner kernel that slows the whole
socket can lose end-to-end. Measure IPC and frequency before and after (hard rule #5).
