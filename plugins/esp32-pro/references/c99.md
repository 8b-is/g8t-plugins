# C99

## Baseline
- C99 is the baseline for ESP-IDF components.
- `-ffreestanding` for bare metal (no libc assumed).
- Fixed-width types from `<stdint.h>`: `uint32_t`, `int16_t`, etc.

## Patterns
- Ring buffers for ISR → main handoff (lock-free, single producer / single consumer).
- `volatile` + compiler barrier (`__asm__ volatile("" ::: "memory")`) for shared flags.
- `#pragma GCC diagnostic` only where justified; never silence `-Wall -Wextra`.

## Anti-patterns
- VLAs in ISRs (stack usage unbounded).
- `malloc` in the tick loop.
- Non-atomic read-modify-write on shared 32-bit flags on a 32-bit core (actually atomic on aligned, but use `atomic_fetch_or` from `<stdatomic.h>` if C11 available; otherwise disable interrupts around the section).

## ESP-IDF component
- `CMakeLists.txt` with `idf_component_register(SRCS ... INCLUDE_DIRS ...)`.
- `Kconfig.projbuild` for user-facing options.
